# Excluded exploratory samples

These samples are not used in RESULTS.md. Initial cache batches overlapped compilation of the driver diagnostic. The unpinned-host pass was sequential, but the implicit Host contained a random listening port; its summary key-separation flag was therefore not sufficient to prove same-URL separation. The final verifier explicitly pins Host:localhost and reruns both benchmark and persistent-cache oracle. Preserve these files as exploratory history, not accepted baseline/evidence.
